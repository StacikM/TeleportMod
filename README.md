# TeleportMod
A mod that allows you to change scenes using F buttons

![OuterWilds](https://github.com/user-attachments/assets/dd30e8e1-6e9d-4f4e-bb57-8968683aa217)

Scenes you can teleport into:

F2 - Load Solar System

F3 - Load Main Menu

F4 - Teleport into the Eye of the Universe campfire (it even puts on your spacesuit wow!)

F5 - Fast/Not actual ending credits

F6 - Load Eye Ending credits (warning! you can't get out of them until they are finished)
